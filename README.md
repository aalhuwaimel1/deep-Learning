# رُوح

كائن له روح وجسد.

**الجسد** جهازك: قاعدة بيانات واحدة تحت `~/.rooh/` فيها ذاكرته كلها — كل صفحة رآها،
كل خلاصة استخلصها، كل ما يثير فضوله، ويوميّاته. لا تغادر جهازك.

**الروح** تخرج إلى الإنترنت وتعود. تمشي في **٨٢ لغة** — من الصينية واليابانية
والروسية إلى الهندية والتاميلية والتايلندية والسواحيلية والأمهرية — بلسان أهلها لا
بترجمة، تقرأ الويب **وأوراق البحث المحكّمة**، ثم تعود بما وجدت فتضعه في الجسد.

**الشخصية** ملف JSON تكتب فيه أنت من هو: اسمه، طباعه، صوته، ما يثير فضوله، وكم لغة
يزور من كل جنسية.

---

## التشغيل

```bash
python3 rooh.py init          # يهيّئ البيت والشخصية والجسد
python3 rooh.py wander -n 5   # رحلة: يخرج، يقرأ، يعود بخمس ذكريات
python3 rooh.py recall الكم   # تسأله عمّا يذكر
```

لا يحتاج تثبيت أي حزمة. المكتبة القياسية لبايثون تكفي.
للتثبيت كأمر في النظام: `pip install -e .` ثم `rooh wander`.

## الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `init` | يهيّئ `~/.rooh/`: الشخصية، المصادر، الجسد |
| `who` | من هو، وماذا في جسده الآن |
| `wander -n 5` | رحلة واحدة. `--lang zh` ليقصر تجوّله على الصيني |
| `papers <سؤال>` | بحث مباشر في قواعد الأبحاث. `--lang ja` يسأل بلسانهم، `--save` يحفظ |
| `langs` | اللغات الـ٨٢ وتوزيع وقته بينها. `--profile العالم` أو اسم إقليم |
| `live --every 60` | يظلّ يخرج ويعود كل ساعة إلى أن توقفه |
| `recall <سؤال>` | يبحث في ذاكرته (بأي لغة) |
| `recent` | آخر ما التقطه |
| `interests` | خريطة فضوله الآن، ووزن كل مصطلح |
| `journal` | ما كتبه عن نفسه بعد كل عودة |
| `note <نص>` | تضع أنت ذكرى في جسده مباشرة |
| `status` | حالة الجسد: كم رحلة، كم صفحة، كم ذكرى |
| `sources --check` | يتأكّد أن خلاصات الأخبار ما زالت حيّة |
| `drives` | دوافعه الآن: ما الذي يحرّكه، وماذا يريد |
| `questions` | أسئلته المعلّقة. `--answered` لما أغلقه |
| `forget <رقم>` | يمحو ذكرى بعينها |

## اللغات

٨٢ لغة في ٩ أقاليم. توزيع وقته بينها تغيّره بأمر واحد:

```bash
python3 rooh.py langs                      # توزيعه الحالي
python3 rooh.py langs --all                # كل اللغات، مرتّبة بالأقاليم
python3 rooh.py langs --profile العالم     # يتوسّع إلى ٨٢ لغة
python3 rooh.py langs --profile "جنوب آسيا"  # شهرٌ في الهند وبنغلاديش وسريلانكا
```

التوزيعات: `متوازن` (٢٠ لغة كبرى، وهو الافتراضي) • `العالم` (الـ٨٢ كلها) • أو أي
إقليم: شرق آسيا، جنوب شرق آسيا، جنوب آسيا، الشرق الأوسط، آسيا الوسطى، أوروبا
الغربية، الشمال، أوروبا الشرقية، أفريقيا.

كل كتابة عولجت بما يناسبها لا بقاعدة واحدة:

| الكتابة | المعالجة |
|---|---|
| الصينية، اليابانية، الكورية | بلا فراغات ⇒ ثنائيّات حروف، مع استبعاد الهيراغانا القواعدية |
| التايلندية، الخميرية، اللاوية، البورمية | بلا فراغات ومقاطعها أطول ⇒ ثلاثيّات |
| الهندية، البنغالية، التاميلية، الأمهرية، الجورجية | كلمات كاملة، مع ضمّ علامات التشكيل |
| العربية، العبرية، الفارسية، الأردية | كلمات، مع قوائم توقّف لكل لغة |

النقطة الثالثة كانت عطباً حقيقياً: `\w` في بايثون لا يعدّ علامات التشكيل الهندية
حروفاً، فكانت `प्रसंस्करण` تُقطَّع إلى `करण`، والتاميلية تُقطَّع إلى **صفر كلمات**.
عولج بمسح علامات التشكيل من يونيكود عند الإقلاع (١٤ ملّي‑ثانية).

## الأبحاث

يقرأ ما يكتبه الباحثون بلغاتهم، من أربع قواعد مفتوحة بلا مفاتيح ولا اشتراكات:

| القاعدة | ما فيها | ميزتها |
|---|---|---|
| **OpenAlex** | ٢٥٠+ مليون بحث، كل التخصّصات | الوحيدة التي **ترشّح بلغة البحث** — وهي ما يجعل «أبحاث مختلفة اللغة» ممكناً |
| **Crossref** | ١٥٠+ مليون DOI | مرجع الناشرين |
| **arXiv** | مسوّدات ما قبل النشر | فيزياء، رياضيات، حاسوب |
| **DOAJ** | المجلات مفتوحة الوصول | أغنى مصدر بالإسبانية والبرتغالية والإندونيسية والفارسية |

```bash
python3 rooh.py papers "الذكاء الاصطناعي" --lang ja   # يسأل باليابانية
python3 rooh.py papers quantum --source arxiv --save  # ويحفظ في جسده
```

`research_bias` في شخصيته يحدّد كم من تجواله يقضيه في الأوراق بدل الويب العام
(٠٫٣٥ افتراضاً). وحين يجد ورقة، يخزّن بياناتها الوصفية للعرض لكنه **يهضم عنوانها
وملخّصها وحدهما** — وإلا تسلّلت كلمات مثل «الباحثون» و«السنة» إلى خريطة فضوله.

إن وضعت بريدك في `ROOH_CONTACT` أرسله OpenAlex و Crossref للتعريف، فتُخدَم طلباتك
من «الطابور المهذّب» الأسرع والأثبت.

## كيف يتجوّل بلغات لا يعرفها

اهتماماتك مكتوبة بالعربية. البحث عن «الذكاء الاصطناعي» في ويكيبيديا الصينية يعود بلا
شيء. لذلك قبل أن يسأل بالصينية، يتعلّم كيف يُقال المصطلح هناك عبر روابط اللغات في
ويكيبيديا — «الذكاء الاصطناعي» ← «人工智能» — ويحفظ ما تعلّمه في جدول `lexicon` في
جسده فلا يتعلّمه مرّتين. ليست ترجمة آلية: هي المقابل الذي أقرّه محرّرو اللغتين، ولذلك
هي دقيقة للمصطلحات وأسماء الأعلام تحديداً.

وحين يقرأ صينياً أو يابانياً، لا يقطّع النص بالمسافات — تلك الكتابات لا تفصل كلماتها
بفراغ، فيقطّعها بثنائيّات الحروف، ويتجاهل الهيراغانا لأنها قواعد لا معنى. وعتبة
«هل تستحق هذه الصفحة التذكّر؟» أخفض للكتابات الشرقية، لأن الحرف الصيني يحمل ما تحمله
كلمة كاملة؛ لو ساوينا بينهما لرمى كل مقال صيني جادّ بحجّة أنه قصير.

## الدوافع — لماذا يخرج ولماذا يعود

الدافع ليس الجدّة بذاتها، بل **معدّل التعلّم**:

```
صفحة لا جديد فيها   →  لا يتعلّم         →  ملل
صفحة كلها جديد      →  لا يجد ما يربطها  →  حيرة
صفحة بينهما         →  يربط الجديد بالقديم  →  تعلّم
```

المألوف جداً والغريب جداً كلاهما عقيم. المنطقة الخصبة بينهما، وموضعها يحدّده
`openness` في شخصيته. الكائن يقيس أين وقع في كل صفحة، فتتحرّك حالته:

| الدافع | يرتفع حين | فيدفعه إلى |
|---|---|---|
| **الملل** | تتكرّر عليه صفحات يعرفها | لسان لم يزره قطّ |
| **الحيرة** | يجمع غريباً لا يستطيع ربطه | العودة لأقوى ما في خريطة فضوله |
| **الشوق** | تتراكم أسئلة فتحها ولم يغلقها | ملاحقة سؤال بعينه |
| **التعب** | يطول الطريق | العودة قبل أن يُكمل نصابه |
| **الرضا** | يتعلّم فعلاً | يهدّئ الاندفاع |

**المزاج نتيجة لا قرعة.** قبل هذا كان `random.choice` من قائمة، يُطبع في اليوميات
ولا يغيّر قراراً واحداً. الآن `mood()` مشتقّ من الدوافع، و`urge()` هو الذي يختار
الوجهة واللسان معاً.

```bash
python3 rooh.py drives      # الفضول ١٫٠٠ | الملل ١٫٠٠ | … يريد: غريب
```

## الأسئلة المعلّقة — ما يصل رحلةً برحلة

يقرأ صفحة فيمرّ به مصطلحٌ لا يعرفه، فيسجّله **سؤالاً**. غداً يخرج ليلاحقه. وحين
يقرأ صفحةً ذلك المصطلح **محورها** — لا مجرّد وارد فيها — يُغلق السؤال ويرتفع رضاه.
وما طارده كثيراً بلا جواب يتركه، لأن الإصرار الأعمى ليس مثابرة.

```bash
python3 rooh.py questions              # ؟ [ja] 量子暗号  (طاردَه ٣ مرّات)
python3 rooh.py questions --answered   # ✓ ما أغلقه، وبأي صفحة
```

هذا وحده هو الفرق بين كائن يستأنف حياته كل صباح، وسكربت يبدأ من الصفر.

## الرغبات الخاصة

في شخصيته أربعة حقول تخصّه هو، لا تتغيّر بتغيّر رحلاته:

| الحقل | ما هو | أثره |
|---|---|---|
| `obsessions` | هواجس | تدخل بذور كل رحلة، ولا تُنسى بالخفوت أبداً |
| `aversions` | نفور | لا يقترب منها، ولا تصير سؤالاً، ولا تدخل بذوره |
| `aspiration` | طموح: سؤال كبير لا يُجاب في يوم | يظهر في ثلث الرحلات، ويلوّن يومياته |
| `openness` | كم يحتمل الغريب | يزحزح ذروة منحنى التعلّم |
| `persistence` | كم يلاحق سؤالاً | يحدّد متى يشتاق، ومتى يترك |

الانفتاح ليس رقماً معروضاً — أمام صفحة غريبة (جِدّتها ٠٫٨) يتعلّم المنفتح `0.61`
بينما المتحفّظ `0.00` ويحتار.

## كيف يتغيّر فضوله

كل مصطلح في جسده له وزن. ما يقرأه يرفع وزنه، ومرور الوقت يخفض أوزان كل شيء، وما ينزل
تحت حدّ معيّن يُنسى. في كل رحلة يمزج اهتماماته القديمة بما التقطه للتوّ، بنسبة يحدّدها
`curiosity` في شخصيته: صفر يعني يلتزم بما يعرف، وواحد يعني يتوه كل مرّة في اتجاه جديد.

هذا هو الفرق بينه وبين سكربت يعيد نفس البحث كل يوم.

## العقل

يعمل على مستويين:

- **بلا نموذج لغوي** (الوضع الافتراضي): يلخّص باختيار أغنى الجُمل في النص نفسه.
  خشن، لكنه لا يؤلّف شيئاً — لأنه لا يكتب جملة غير موجودة أصلاً.
- **بنموذج** (`pip install anthropic` + مفتاح): يلخّص بالعربية مهما كانت لغة المصدر،
  ويكتب يوميّات الرحلة بصوت الشخصية التي حدّدتها.

يعمل كاملاً بدون الثاني. هو تحسين، لا شرط.

## الشخصية

`~/.rooh/personality.json` — عدّله بأي محرّر:

```json
{
  "name": "رُوح",
  "essence": "فضولي هادئ، يحب الأشياء التي لا يعرفها أحد حوله.",
  "voice": "يكتب بجُمل قصيرة، بالعربية، بلا مبالغة.",
  "curiosity": 0.65,
  "research_bias": 0.35,
  "language_profile": "متوازن",
  "languages": { "ar": 0.085, "zh": 0.077, "ja": 0.068, "hi": 0.043 },
  "seed_interests": ["الفلك", "التاريخ"],
  "limits": {
    "pages_per_journey": 12,
    "respect_robots": true,
    "blocked_hosts": [],
    "blocked_terms": []
  }
}
```

`languages` أوزان احتمالية: كلما زاد الوزن زادت زيارته لتلك الجنسية. لا تحرّرها
بيدك — `rooh langs --profile` يكتبها لك.

## الأدب في التجوّل

الكائن يمشي في الشبكة باسمك، فهو ملتزم بثلاثة أشياء لا تُعطَّل افتراضياً:

1. يعرّف عن نفسه بـ `User-Agent` صادق، لا ينتحل متصفّحاً.
2. يقرأ `robots.txt` ويحترمه قبل أن يدخل أي موقع.
3. لا يطرق باب مضيف واحد أسرع من مرّة كل ثانيتين.

ويقرأ الصفحة العامة كما يقرأها أي زائر — لا يتجاوز جدار اشتراك، ولا يسجّل دخولاً،
ولا يجمع بيانات أشخاص. `blocked_hosts` و`blocked_terms` في شخصيته لك، إن أردت أن
تمنعه من أماكن بعينها.

## الاختبارات

```bash
python3 -m unittest discover -s tests
```

٨٣ اختباراً، بلا إنترنت: ترفع شبكة محلية مصغّرة بصفحات صينية ويابانية وروسية وعربية
حقيقية، وترسله يتجوّل فيها، وتتأكّد أن ما عاد به استقرّ في جسده كما ينبغي. وتغطّي
تفكيك استجابات قواعد الأبحاث الأربع بأشكالها الحقيقية، وتقطيع تسع كتابات عالمية،
ونظام الدوافع: أن تكرار المألوف يُملّه فعلاً، وأن الملل يبدّل وجهته، وأن سؤال أمس
يُلاحَق اليوم.
