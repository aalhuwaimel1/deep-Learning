🛣️ What is SADE-IoV?

SADE-IoV is security software that runs inside a connected car's communication unit (OBU). It is not a self-driving system. As the car drives and exchanges wireless V2X messages with nearby cars and roadside units, SADE-IoV constantly watches for attacks and automatically changes how strongly each message is encrypted.

1Senses the situation — signal strength, traffic, message rate.
2Scores the threat with a machine-learning model (0–100).
3Adapts protection — calm road → fast light encryption; under attack → strong AES-256, hardware identity checks, then channel isolation.

This page simulates that software on a Riyadh journey so you can watch it react. Pick a trip length and press Start — you'll get a full report at the end.
